# bank-marketing-data-quality-workflow
# Overview
This project demonstrates a repeatable data preparation workflow using Python and pandas. It focuses on loading, inspecting, cleaning, and validating tabular data before preparing it for analysis.

# Objectives
Inspect dataset dimensions, data types, missing values, and duplicates.
Standardise column names and categorical values.
Identify and document at least five data quality issues.
Validate data ranges, uniqueness, and consistency.
Separate raw, interim, and processed datasets.
Export a validated analytical dataset and document its fields in a data dictionary.

# Tools and Technologies
Python
pandas

# Project Structure
data/raw/: Original, unchanged source data.
data/interim/: Intermediate outputs produced during cleaning.
data/processed/: Validated analytical dataset.
notebooks/: Exploratory profiling and cleaning notebook.
src/: Reusable Python scripts.
reports/: Data quality report and data dictionary.

# Expected Deliverables
A notebook profiling the original dataset.
Documentation of at least five data quality issues.
A repeatable cleaning and validation workflow.
An exported, validated analytical dataset.
A short data dictionary and data quality report.

# Reproducibility
The workflow will document its dependencies, cleaning decisions, validation rules, and outputs so that the process can be repeated on the same source dataset.
